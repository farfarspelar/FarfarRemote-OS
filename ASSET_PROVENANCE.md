# FarfarRemote asset provenance

## Generated FarfarRemote graphics

The project owner states that the FarfarRemote UI graphics and visual reference images were generated with ChatGPT from prompts written by the project owner. The owner directed the design, supplied the prompts, and integrated the resulting images into the app as UI assets or references.

This applies to the supplied FarfarRemote asset packs, including the base remote controls and the Settings graphics in `FarfarRemote_Asset_Pack/`, `FarfarRemote_Settings_Assets_v0.3/`, and the selected Android derivatives in `app/src/main/res/drawable-nodpi/`. Original supplied files are preserved separately; derivatives are described in [graphics/README.md](graphics/README.md). Full-screen mockups are design references and are not used as app backgrounds.

The remote buttons, logo, Settings backgrounds, coffee cup, and other visual artwork are project graphics generated for FarfarRemote. No official Kodi logo or official Buy Me a Coffee logo is included. The coffee cup is generic and is not represented as official Buy Me a Coffee branding. The word “Kodi” identifies the supported third-party product; Kodi remains the property/trademark of its respective owner. “Buy Me a Coffee” is the third-party service name used to identify the external support link.

## Project-authored code and system graphics

Java application code, XML drawables, views assembled in Java, and build scripts are project-authored source code covered by the repository's GPL-3.0 license. Android-provided platform widgets and system UI are supplied by Android and are not project artwork.

## Runtime and documentation images

Kodi poster, thumbnail, and other media artwork are obtained from the user's Kodi server at runtime; they are not bundled as FarfarRemote graphics. The screenshots in `docs/screenshots/` are captures of FarfarRemote on the project test device, not generated mockups. They show no configured Kodi endpoint or account credentials.

The provenance above records the project owner's account of how these assets were created. It does not make a claim on Kodi's trademarks or on Android-provided system assets.
